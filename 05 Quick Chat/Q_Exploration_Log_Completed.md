- **When would you use Q vs. the dashboard to answer a business question?** Use Q when you need ad-hoc analysis, custom calculations, or cross-dataset joins (e.g., combining ticket data with deal revenue). Use the dashboard for quick visual overviews, trend monitoring, and pre-built KPIs that stakeholders have already agreed upon. Q is better for exploratory questions; the dashboard is better for standardized reporting.
